# Renderer Optimization Archive

**Status:** HISTORICAL / SUPERSEDED / REJECTED EVIDENCE

This folder contains the chronological optimizer experiments and diagnostic branches that led to the accepted v1.2.1 / EXP4A implementation.

Do **not** choose an implementation baseline by finding the newest-looking EXP file here.

Current accepted conclusions live under [../findings/](../findings/).

Important historical lessons preserved here include:

- EXP2 register/ABI corruption;
- EXP2R2 hard-coded PRX address crash;
- EXP2S startup-loop stride mismatch;
- one-hook Practice/Gold evolution;
- incorrect early winner-glow acceptance;
- UV identity and later-slot winner-glow investigation;
- release-readiness analysis.

Historical tool paths may refer to the former `research/tools/` location. Current utilities live under `tools/research/`.
