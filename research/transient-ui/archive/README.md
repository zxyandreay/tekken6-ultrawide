# Transient-UI Experiment Archive

**Status:** ACTIVE RESEARCH

Rejected, superseded, diagnostic, and chronological experiment notes belong here.

Preserve failures that establish useful constraints. Each archived experiment should clearly state:

```text
Status: REJECTED / SUPERSEDED / DIAGNOSTIC
Parent artifact/hash
Hypothesis
Exact changes
Device result
Why it was not accepted
What the next experiment learned from it
```

The archive must not be treated as the current implementation baseline. Accepted conclusions move to [../findings/](../findings/).
