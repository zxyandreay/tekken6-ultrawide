# Automatic Aspect Research

**Status:** COMPLETE / HISTORICAL FOUNDATION

This research established automatic PPSSPP display-aspect detection for Tekken 6 and replaced the earlier fixed/manual aspect-selection workflow.

The accepted plugin architecture now derives 3D and HUD correction from PPSSPP's current landscape aspect at runtime.
